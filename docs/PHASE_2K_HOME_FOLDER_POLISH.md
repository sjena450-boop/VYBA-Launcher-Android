# Phase 2K — Home Folder UI Polish

## Changes
- Replace the generic apps glyph on home folder tiles with a dedicated folder-open glyph.
- Show the folder's app count in the folder dialog title.
- Make the folder destination picker scrollable so users with many folders can reach every destination.
- Make folder contents scrollable so large folders do not overflow the dialog.
- Clear temporary app selection when leaving Home Edit Mode.

## Scope
This is a UI refinement of the existing local folder-management flow. It adds no dependencies, network services, or recurring costs.

## Not included
Direct drag-and-drop onto a folder icon is intentionally not represented as complete in this phase. The current supported flow is to select apps in Edit Mode and use **Add to folder**.
